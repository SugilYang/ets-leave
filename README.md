# ETS 연차 자동반영

다우오피스 **휴가 신청서**를 매일 06:00에 읽어 실적공수 앱에 '연차'로 자동 입력합니다.
사내 서버 PC(내방객 자동화가 도는 PC)에서 창을 켜 두면 계속 돕니다.
(GitHub Actions 는 다우오피스 해외 IP 차단 때문에 쓸 수 없음)

## 설치 (한 번만)
1. 서버 PC에 폴더 만들기: 예) `C:\ets-leave`
2. 이 저장소의 파일 4개를 그 폴더에 복사: `leave_sync.py` `daou.py` `실행.bat` `.env.example`
3. `.env.example` 을 복사해 `.env` 로 이름 바꾸고 다우 아이디·비밀번호를 채움
4. 명령 프롬프트에서 한 번: `pip install beautifulsoup4 requests playwright` 그리고 `playwright install chromium`
   (내방객 자동화가 있는 PC면 playwright 는 이미 있음)
5. `실행.bat` 더블클릭 → 창에 "다우 로그인 성공 … 반영 N건" 나오면 정상

## 실행
- `실행.bat` 더블클릭 → 창이 뜨고 "연차 자동반영 대기 중" 상태로 계속 돕니다. **이 창을 닫지 마세요.**
- 켠 날 아직 안 돌았으면 바로 한 번 실행하고, 이후 매일 06:00 에 자동 실행
- PC 재부팅 후 자동으로 뜨게 하려면: `실행.bat` 바로가기를 `Win+R` → `shell:startup` 폴더에 넣기
- 실행 기록은 창에 바로 보이고, 문제가 있으면 창 내용을 캡처해 보내면 됩니다

## 동작
- 공수 입력 대상자(조직도 − 제외자)가 기안한 휴가신청서만 열람
- 결재 완료 문서는 `seen_docs.json`에 기억해 다시 열지 않음 (진행중 문서는 결재 완료까지 매일 확인)
- 어제 ~ 2주 뒤 휴가일을 연차 8h / 반차 4h / 반반차 2h 로 입력
- 주말·공휴일·이미 입력된 날·결재 상신된 주는 건너뜀
- 결과는 관리자 다우 알림으로 통보
